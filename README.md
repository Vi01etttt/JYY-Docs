# Vibe Coding 学习讲义 · jyy《生成式软件工程》

贯穿始终的立场：vibe coding 不是"一句话生成应用"，而是研究**怎样让 AI 加速的工程不失败**。

## 推荐顺序

1. **第 1 讲 欢迎来到未来**：建立问题意识。
2. **第 2 讲 提示词与上下文工程**：最实用的一讲，建议精读。
3. **第 8 讲 Agent Native 开发**：把反馈做成工程系统。
4. **第 9 讲 DeepSeek Harness**：从一个小 Agent 看架构怎样容纳需求变化，最后看。

## 学法

沿用第 2 讲的建议：

1. 先看视频。
2. 合上资料，用自己的话复述。
3. 让 AI 追问含糊处、给出反例。
4. 对照讲义原文核对。
5. 再讲一遍。复述时卡住的地方，就是知识缺口。
